# Slideshow posting preferences

Apply these preferences to future TikTok slideshow batches for @try.flagd and @nomoreawkwardness, and other slideshow accounts unless the user specifies otherwise.

- Catchy posting titles must be fewer than 60 characters (59 characters maximum), including spaces and punctuation.
- Prefer fuller, catchy hooks with enough context to make the situation clear. Use the available space when helpful; keep the wording natural.
- Keep the long description separate from the catchy title and the text on the slides.
- Check each posting title's character count before delivering a batch.
- Write slide text, titles, and descriptions in natural, conversational language, like someone talking to a friend. Use everyday words and contractions; avoid formal, book-like prose.

These preferences were confirmed on October 6, 2026 and updated on October 9, 2026.
