# Everyday reactions

User feedback: the first two rounds' movement was acceptable, but the backgrounds,
lighting and clothing still looked too polished and synthetic. The user approved up
to $5 for this separate round.

Four four-second reactions: skeptical hallway glance, tired bedroom exhale, suppressed
kitchen laugh, and a small bus-stop double take. Each has a different practical outfit,
specific incidental surroundings and less flattering everyday light. These change several
creative choices together and do not isolate which individual change drives preference.

The initial frames in this recorded round predate the user's standing U.S. residential
environment rule. The runner now appends that rule whenever it generates a replacement
frame. The hallway and bedroom outputs in this round are retained as historical reaction
examples, not references for future residential scenes.

Use the existing synthetic master character reference, Nano Banana Pro at 1K, and Kling
3 Standard with audio off. Planned media cost is $1.88 (four images and four clips),
plus image input/text token charges. The $5 ceiling allows bounded replacements following
visual inspection; do not automatically retry paid submissions after ambiguous failures.

The runner reserves submissions on disk and resumes existing animation requests. Inspect
the frames before creating `scenes-reviewed.txt` and starting the animation phase. Keep
all rejected frames and video attempts for comparison. Production changes are outside
this experiment.
