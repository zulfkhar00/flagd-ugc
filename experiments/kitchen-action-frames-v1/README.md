# Physically occupied kitchen starting frames

Six still-only candidates using the approved synthetic character, established U.S. kitchen
direction, and the selected `mid-action-reach` composition as the benchmark. Each frame
starts during a mundane task; prompts avoid reaction or look-away behavior. No animations
are included in this pass. If frames are selected, use the unchanged minimal motion prompt
at `../us-home-scenes-v1/motion-prompt-v5-kitchen.txt`.

The first image pass produced several mirror/visible-phone compositions, so five candidates
were replaced using the explicit live-front-camera instruction. The review set is one
retained original and five replacements. Model: Gemini 3.1 Flash Image, 1K. Estimated total
output cost: approximately $0.737, excluding minor input-token charges. No animation calls
have been made.
