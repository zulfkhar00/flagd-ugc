# Task-driven UGC across home and car contexts

Six one-frame-per-context samples test whether the task-focused gaze and movement rule
generalizes beyond the kitchen: bedroom, bathroom, living room, entryway, parked car and
laundry. Each accepted still is paired with one three-second task-continuation clip.

Estimated base cost: $0.402 for six Gemini 3.1 Flash Image 1K stills plus $1.512 for six
Kling standard clips, about $1.914 total before any still replacements. The experiment is
reviewed against `../TASK_DRIVEN_UGC_RULE.md`; no reaction arc is requested.
